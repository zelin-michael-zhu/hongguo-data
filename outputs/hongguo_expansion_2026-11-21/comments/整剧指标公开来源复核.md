# 整剧播放量和追剧计数的公开来源

核验日期为 2026 年 11 月 21 日。目标是判断能否给现有目录作品补齐当期的两个整剧字段。

| 来源 | 此次检查 | 可支持的结论 |
|---|---|---|
| 红果官网 | 《人人嫌猎户粗野，唯有我听见他真心藏情》详情页与默认播放页均返回 HTTP 200。详情页整剧社交数据包含热度、评分、评分数、热评、收藏数和点赞数；默认播放页的整剧社交数据仅含收藏数。 | 样例官网作品页没有返回整剧播放量或单独的追剧计数。不能把收藏或热度填进这两列。[样例详情](https://hongguoduanju.com/detail?series_id=7684955951031389209) · [默认播放页](https://hongguoduanju.com/player/7684955951031389209) |
| hongguo-data 免费目录 | 公开发布的摘要返回 200；仓库文档列出的剧集目录字段为 ID、标题、封面、简介、标签、集数、频道、日期。 | 下载这份元数据不补足目标指标。[数据仓库](https://github.com/wmefanit/hongguo-data) |
| HongguoTrending 学术档案 | 原论文列有点赞、收藏、评论、分享和热度。依其附录 F 尝试样例作品与样例快照条目，两次均返回 HTTP 403。 | 未验证可用的播放量、追剧数响应。[论文附录 F](https://arxiv.org/html/2611.19351v1) · [学术档案](https://micro-drama.rongxin.me/) |
| openhongguo 非官方 SDK | 作者列出批量加载作品与分集功能。SDK 模型文档将 PlayCount 定义为整剧播放量，把 FollowCount 描述为作品标题旁计数。README 说明请求统一使用注册的匿名设备，部分请求需要签名，服务端没有公开接口文档；未明确承诺批量元数据读取可独立于这些机制。 | 以往取得的样本说明有相关字段。文档不能证明任意作品均可读，也未确定 FollowCount 等同于订阅。此复核未为读取目标计数调用未公开服务端接口。[项目文档](https://github.com/beilunyang/openhongguo#readme) · [模型字段](https://pkg.go.dev/github.com/beilunyang/openhongguo/sdk/model) |

第三方 SocialDataX 的产品文档也列有整剧播放计数字段，之前的项目测试停在 API Key 验证。由于这次只使用免费来源，未购买或调用业务接口，没有纳入实际新增数据。[服务方输出文档](https://apify.com/socialdatax/socialdatax-hongguo-data-api/output-schema)
