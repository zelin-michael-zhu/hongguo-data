# 在已经读到剧名和季号后，过去榜单还能提供多少预测信息？

主指标计算入榜后第 1 至 7 个自然日内累计在同榜前百的天数，每次入榜都有 0 至 7 的整数结果。比较的是同一批测试事件上预测天数的平均绝对误差（MAE），越小越准。次要指标为第七天是否仍在榜，以及首日名次 21–100 的作品未来七天是否冲进前二十。后两项使用概率预测和 Brier 分数，越小越准。预测仅针对每日已发布榜单的记录。

## 时间与信息

把 11 月 2–5 日、6–9 日和 10–14 日依次作为三个测试窗口，每窗开始前固定模型，预测整窗。只训练那些入榜后第七天严格早于窗口开始日，而且完整观察到结局的事件。三个窗口共有 193、204、250 个测试事件，训练事件分别 443、443、492 个。前两个窗口之间没有新成熟的训练标签，因此它们用了同一个拟合结果。测试日期不重叠，但日期邻近、部分七日结局重叠，一些系列反复出现。这是已知短期档案上的回放，后续还需要新时间段验证。

所有模型使用相同训练、测试实例。特征的数值中位数填补、缺失标记和标准化参数均只用训练数据。训练中恒定的列以及经标准化后完全同值或方向相反的列只留一份，避免同一缺失信号被重复编码并改变正则化力度。天数用线性岭回归并把预测截在 0–7 天。二元结局用岭逻辑回归，所有模型的岭惩罚取固定值 10，截距不惩罚。没有在这 13 个验证日上挑超参数。

| 代号 | 输入 |
|---|---|
| A | 榜种、入榜名次、名次曲线（第 25、75 位固定分段点）、榜种与名次的交互、首次观察或重进标志、周内正弦/余弦项。 |
| B | A 加当日热度、点赞、收藏、评分。热度和两类互动计数用 log(1+x)。 |
| E | B 加单个“昨日有可识别同系列作品”标志。 |
| G | B 加当时档案题名能否据规则识别季组，以及当天题名标出的季号。只需看静态信息。 |
| C | G 加同系列其他作品的昨日在榜数、昨日最佳名次、近期动量、此前可识别的其他作品数、此前占榜日数。这个 C 对 G 的差异才量到动态历史的额外贡献。 |
| F | B 加当时题名能否识别季组、昨日同组数、昨日同组最佳名次；可查看更小的信息组合。 |
| J、D | 对应 G、C，但允许以 11 月 21 日核实的官网组号回连历史，只作事后情景。 |
| H、I | 对应 G、C，另加此前七日的完整天数及观察窗口起点造成的历史不足标志。 |

## 结果

| 以后七天累计在榜天数的 MAE | 11/02–05 | 11/06–09 | 11/10–14 | 合计 647 次 |
|---|---:|---:|---:|---:|
| A 入榜状态 | 2.140 | 2.045 | 2.245 | 2.150 |
| B 加自身表现 | 1.911 | 1.917 | 2.065 | 1.973 |
| E 再加昨日是否有同组作品 | 1.910 | 1.917 | 2.068 | 1.973 |
| G 整合自身表现与静态季标 | 1.704 | 1.651 | 1.872 | 1.752 |
| C 再加历史表现 | 1.802 | 1.638 | 1.886 | 1.783 |

从 B 到 C 看上去改善 0.190 天。然而 G 已比 B 改善 0.220 天。以 G 为商业可用基线，C 的平均误差多 0.031 天，三个窗口中只有第二个稍好。H 对 I 为 1.748 对 1.781。用 J 与 D 也得到 1.752 对 1.798。去掉《持械入宋》的所有训练和测试实例、重新拟合，G 与 C 为 1.746 对 1.790。只在测试时评估此前七天齐全的 351 次，G 与 C 为 1.840 对 1.842。带季号作品与缺季号作品构成并不相同，G 的预测表现不等于标注季号会改变观看行为。

647 次测试事件中，261 次在第七天仍在榜。对于该结局 G 与 C 的 Brier 为 0.16982 与 0.17542。另有 563 次从首日 21–100 位起步，其中 75 次未来进入前二十。G 与 C 的 Brier 为 0.08960 与 0.08940，ROC-AUC 为 0.833 与 0.832，平均精确率为 0.527 与 0.531。幅度小，不同指标略有出入。各窗实际与预测均值、校准截距斜率及其他性能指标均已保存。再次入榜和有确认同系列历史的部分子样本尤其少，事后挑一个最好的榜或季号不能建立稳定的运营规则。

例如，11 月 5 日漫剧榜第 97 名新进的《末世选择，从解析神明开始成神第二季》，前一天同组作品排名第 10。G 预测随后七天在榜约 1.8 天，C 预测约 4.7 天，实际只有 1 天。同日第 5 名的《伪人降临！我是全场唯一预言家第五季》，前一天同组作品排名第 68，G、C 分别预测 5.7 与 7 天，实际 7 天均在榜。两例用来展示预测的含义；选择规则的依据应当是全体时间外误差及其不确定性。

补充拆分单独使用 G 作基准。加昨日同组作品数量与最佳名次，合并 MAE 高 0.004 天；加以往其他作品数与累计在榜日，高 0.018 天；只加近期动量，高 0.011 天。前两项处理中，昨日信息在前两个窗略有改善、第三窗变差，历史深度三个窗都未改善。这是对同一测试批次的探索性诊断，不能据此再选实用规则。[各窗口拆分](dimension_summary.csv) · [逐事件拆分预测](dimension_oos.csv)
