# 红果预约榜与首周收藏日采

「红果预约榜与首周收藏追踪」每天北京时间 23:15 运行。原样本为 2026 年 11 月 22 日官网预约榜的 100 个作品 ID。后续预约榜按日期归档，首批比较继续使用这 100 部。

```sh
python3 outputs/hongguo_reservation_pilot_2026-11-22/track_reservations.py
```

## 上线日与首周收藏

- 预约榜没有显示榜单更新日，按实际北京时间记录每页。新剧榜同时核对官网日期标签。正片页面按作品和首集 ID 核验，记录官网首见字段及实际抓取时间。遇到预约和正片 ID 不同时，只有官网新剧榜唯一标题、简介和类型均吻合，且正片首集通过核验，才采用该候选 ID。
- D0 使用官网网页首见口径。确认正片时，如果当天观察到同一 ID 从不可见变为可见，或同时有当天官网首见字段，则记录当天收藏。若官网日期早于第一次实测且当天收藏缺失，缺失留空。网页日期无法确定 App 的上线时刻。
- D7 使用北京时间 D0 加七个自然日，从同一默认播放页读取同一字段。抓取时刻偏离七天超过一小时的配对留档，暂不纳入首周比较。错过明确的 D0 或 D7 时，不用其他日期补数。

## 分组与比较

- `cohort_identity_initial.csv` 保留初始身份依据。只有得到可核来源时，在 `cohort_identity_updates.csv` 记录更新。身份取 `first_work`、`sequel` 或 `unknown`。确认是衍生番外时将 `exclude_main_comparison` 标为 1，日采仍继续跟踪。没有明确季数的作品待核验。仅复算已存文件可以用同一命令加 `--rebuild`。
- 对于有完整首周收藏的作品，取严格早于核实上线时间的最后一条含两项信号的预约榜快照。两项信号使用同一批作品。分别报告首部、续季的样本数和 Spearman 相关，并统计两项信号给出相反排序时各自正确的次数。同类型比较保留为敏感性核查。

`tracking/首批100部_上线与首周收藏.csv` 保存 100 部的追踪状态。每个日期目录下的 `summary.json` 保存当日覆盖及各组分母，`comparison.json` 保存当日复算结果。访问异常通过同日的请求记录和 `run_issues.json` 核对。
